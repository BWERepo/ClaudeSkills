# BWE-WOW design guide

## Assessment prompts (answer from the rendered page)
First impression in 5 seconds; what the page is for and the one primary action; type scale, weights and measure; colour roles (brand, text, surface, accent, status); hierarchy and focal point; grouping and density; navigation clarity; control and form appearance; how results are shown; mobile reach and tap targets; contrast and focus visibility; does it look trustworthy and finished.

## Mode detection (wow.mjs detect scores these signals)
GENERAL default. TOOLS inputs plus a result area, calculator/converter words. LANDING marketing sections, call-to-action words, no inputs. ECOMMERCE price, cart, product, stock words. DASHBOARD tables, charts, filters, status words. FORMS forms with many fields and labels, no result area. CONTENT articles, long paragraphs, guide/FAQ words. NAVIGATION mostly links, nav landmarks. PORTFOLIO image heavy, gallery words. CUSTOM when none fits. Close scores: say so and ask.

## Design personalities
Professional, elegant, playful, technical, creative, luxurious, friendly, minimal, bold, editorial, modern, traditional. Choose from audience, purpose, brand and content complexity; state the choice and why.

## Direction briefs (starting points, not templates)
- **A Premium Refined:** sophisticated type pairing or a single refined family with strong scale, firm hierarchy, controlled palette (one accent), generous but purposeful spacing, precise alignment, subtle depth.
- **B Bold Distinctive:** confident oversized headline or answer, purposeful high-contrast colour blocks, distinctive component shapes, memorable first screen, one signature element.
- **C Modern Interactive:** application-like layout, refined states (hover, focus, loading, success, error), purposeful micro-motion, engaging controls, progressive disclosure of detail.
They must differ in composition (what is the focal point, how content is grouped), not only in colour or font. Generic gradients, stock glassmorphism and identical card grids are rejected.

## Mode patterns
- **Tools:** the answer is the visual centerpiece; Quick answer first (one sentence a person can act on), Detailed answer in an expandable region; inputs labelled, units visible, sensible defaults kept; copy/share only if the tool already has it; never alter calculation code or displayed numbers; examples and assumptions stay.
- **Landing:** headline states the value; one primary call to action above the fold; existing proof only (no invented testimonials or numbers); sections tell a short story.
- **Ecommerce:** gallery and price clear, options as large selectable controls, stock and shipping facts near the buy button, sticky mobile purchase bar only if it does not hide content.
- **Dashboard:** key figures first, tables with aligned numerals, sticky headers, visible filters, status shown by text plus colour, destructive actions separated.
- **Forms:** visible labels, grouped fields, inline validation text next to the field, clear required marks, progress for multi-step, large touch targets.
- **Content:** 60 to 75 character measure, strong heading steps, callouts for key points, in-page contents for long pages, readable tables.
- **Navigation:** shallow clear structure, visible search, mobile menu reachable with a thumb, current-page indication, no clutter.
- **Portfolio:** let the work lead; consistent aspect ratios; captions; fast images.

## Rules of taste
Restraint beats decoration. One focal point per screen. Few colours with defined roles. Motion only to explain a state change and off under reduced motion. Keep the brand's recognisable colour, logo and tone unless rebranding is authorized.
