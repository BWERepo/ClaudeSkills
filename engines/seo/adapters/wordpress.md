# Adapter: WordPress

| Concern | Where / how |
|---|---|
| Pages | WP admin (Pages / Posts) or the block editor; page templates in the theme |
| Metadata | The SEO plugin already installed (Yoast, Rank Math, SEOPress…) — use it; don't install a second |
| Sitemap / robots | Usually generated by WordPress core or the SEO plugin |
| JSON-LD | The SEO plugin's schema settings; custom blocks only if needed |
| Rendering | Server-rendered |
| Redirects | Existing redirect plugin or host rules |

## Working rules
- The engine usually cannot log into WP admin. Produce page content + metadata + schema + link
  instructions as a handoff document for the person with admin access, unless the project stores
  content in files (headless/Git-based).
- Never install plugins without approval; check plugin conflicts (duplicate schema from theme +
  plugin is common).
