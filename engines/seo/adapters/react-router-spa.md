# Adapter: Vite + React + react-router (client-rendered multi-route SPA)

| Concern | Where / how |
|---|---|
| Routes | Route config (`createBrowserRouter` / `<Routes>`) in `src/` |
| Metadata | Per-route: a head manager already in the project (react-helmet-async etc.) or a small `useEffect` title/description setter; static defaults in `index.html` |
| Sitemap / robots | `public/robots.txt`, `public/sitemap.xml` (static or generated by a script at build) |
| JSON-LD | Per-route via the head manager, or static in `index.html` for the entity |
| Rendering | Client-side: metadata set by JS is seen by Google (renders JS) but not reliably by other crawlers/social previews. Prefer prerendering routes at build if the project already supports it; otherwise note it as a limitation |
| 404 | SPA fallback serves `index.html` with 200 for unknown URLs — soft-404 risk; render a noindex not-found view at minimum |

## Adding a page
Add the route + component using existing layout components; set title/description/canonical via
the project's head mechanism; add to `sitemap.xml`; link from parent pages.

Do not add a head-management dependency without the user's approval — check first whether one
exists.
