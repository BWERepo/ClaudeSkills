# Measurement & reporting (`/BWESEOReport`) → `docs/seo/SEO-MEASUREMENT.md`, `docs/seo/reports/`

Success is defined by the profile's primary conversion (qualified leads, appointments, sales,
prototype requests…), not by rankings.

## Metrics (track what the project can actually measure; mark the rest "not yet measurable")

- Organic impressions, clicks, CTR, average position (Search Console) — site, per page, per query.
- Indexation: indexed vs. submitted (Search Console Pages report).
- Organic landing-page sessions (analytics).
- Conversions from organic: calls, forms, quote requests, bookings, prototype requests, purchases.
- Conversion rate per organic landing page.
- Pages and queries that produce conversions.
- Ranking trends for P1 topics (from Search Console positions — no paid rank tracker unless
  approved).

## SEO-MEASUREMENT.md contents

Primary success metric + definition of "qualified" · baseline numbers with date (or "0 / not
measured") · data sources and how to get each (who exports what, where it goes) · attribution
gaps and the fix recommended · review cadence (monthly report, quarterly strategy review) ·
per-page targets phrased as directions, not promises.

## Monthly report (`docs/seo/reports/<YYYY-MM>.md`)

Period · what shipped (pages created/improved, fixes) · Search Console summary · organic
conversions and which pages/queries produced them · pages needing refresh · next month's plan ·
data caveats. Plain language; no vanity metrics without context.

## Monitoring baseline for new pages

Every newly published page gets a baseline from `/BWESEOPublish`: publication date plus 7-, 30- and
90-day review dates (see `search-console.md`). Over time monitoring covers indexed / not indexed,
impressions, clicks, CTR, average position, queries and query changes, page performance over
time, and conversions where legitimate tracking exists. The monthly report lists pages whose
review is due and the status of each new page's indexing request (REQUESTED / NOT REQUESTED /
UNKNOWN — verified information only).
